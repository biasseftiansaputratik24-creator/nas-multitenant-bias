  
# Project Overview

Latar Belakang

Proyek ini membahas penggunaan Network Attached Storage (NAS) sebagai pusat penyimpanan data yang dapat diakses melalui jaringan lokal.

Konsep multi tenant digunakan agar beberapa kelompok pengguna dapat menggunakan satu infrastruktur penyimpanan dengan hak akses yang terpisah.

Tujuan

1. Mempelajari konfigurasi sistem NAS.
2. Menyusun konsep layanan penyimpanan multi tenant.
3. Mengidentifikasi kebutuhan hak akses pengguna.
4. Menyusun skenario pengujian sistem.
5. Mengevaluasi keamanan dan performa penyimpanan.

Ruang Lingkup

Pengujian meliputi akses client, konfigurasi shared folder, hak akses, transfer file, dan kestabilan layanan NAS.

Lingkungan Sistem

- Server NAS: TrueNAS atau OpenMediaVault sesuai sistem yang diuji.
- Client: Perangkat Windows.
- Protokol berbagi file: SMB/CIFS.
- Jaringan: Jaringan lokal.

Tahap Pengerjaan

Saat ini proyek berada pada tahap testing dan evaluasi. Hasil akhir akan disesuaikan dengan pengujian yang telah dilaksanakan.

Hasil yang Diharapkan

- Layanan NAS dapat diakses oleh client yang berwenang.
- Hak akses tenant dapat dibedakan.
- Transfer file dapat diuji dan diukur.
- Kendala selama pengujian dapat didokumentasikan.
